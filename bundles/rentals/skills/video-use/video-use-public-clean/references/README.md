# references/

Put project-specific reusable docs here. Suggested files:

- `brand-guide.md` — colors, typography, logo safe zones, examples.
- `editor-brief-template.md` — house structure for take selection and EDL generation.
- `subtitle-style.md` — ASS/SRT style, chunking, casing, margins.
- `animation-recipes.md` — reusable lower thirds, diagrams, UI overlay recipes.
- `sample-edl.json` — anonymized example of a good EDL.
- `qa-checklist.md` — visual/audio/subtitle checks before delivery.

Do not put private footage, transcripts, user chats, or provider credentials here.
