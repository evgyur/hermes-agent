# assets/

Put reusable licensed assets here, if your project needs them:

- `fonts/` — caption/overlay fonts.
- `logos/` — transparent SVG/PNG marks.
- `luts/` — color LUTs or grade references.
- `sfx/` — licensed sound effects.
- `music/` — licensed beds/stings.
- `overlays/` — reusable transparent WebM/PNG elements.

Keep large raw footage and generated renders outside the skill. Generated outputs belong in each project's `<videos_dir>/edit/`.
