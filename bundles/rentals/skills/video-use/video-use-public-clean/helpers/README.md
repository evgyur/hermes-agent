# helpers/

- `transcribe.py` — single video to word-level JSON transcript.
- `transcribe_batch.py` — batch transcription for a directory.
- `pack_transcripts.py` — transcript JSONs to compact phrase-level markdown.
- `timeline_view.py` — filmstrip + waveform inspection PNG.
- `grade.py` — color-grade helper.
- `render.py` — EDL render with segment extraction, fades, overlays, subtitles last.
