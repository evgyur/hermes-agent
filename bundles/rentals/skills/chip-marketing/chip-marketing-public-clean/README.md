# marketing-agent-toolkit

Public-clean export of a marketing skill bundle. It contains reusable marketing strategy, growth tactics, content, pricing, persuasion, and launch references.

This archive intentionally excludes private/customer-specific material, local infrastructure notes, access material, chat IDs, private projects, personal workflows, logs, backups, and runtime state.

## Install

Copy this folder into your agent skills directory and load `marketing-agent-toolkit`.

## How to use

1. Open `SKILL.md`.
2. Pick one domain: tactics, ideas, or psychology.
3. Load only the reference file that matches the request.
4. Produce a concrete artifact and verify it against the stated output contract.

## Contents

- `references/tactics/` — executable growth tactics.
- `references/ideas/` — marketing ideas by channel/category.
- `references/psychology/` — behavioral models for marketing.
- `references/playbooks/` — launch/outreach playbooks.
- `references/hook-frameworks/` — reusable hook templates.
- `references/content-syndication/` — platform-native repurposing patterns.
- `references/pricing-alerts/` — generic pricing-monitoring alert scenarios.
