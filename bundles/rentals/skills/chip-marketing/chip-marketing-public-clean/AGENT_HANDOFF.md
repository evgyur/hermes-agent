# Agent handoff

This is a public-clean, reusable marketing skill bundle. It is not a private operator dump.

## What it does

Routes marketing requests into one focused reference domain: growth tactics, marketing ideas, or psychology models. The agent should load only the needed file, produce a concrete artifact, and verify it.

## Entry point

Start with `SKILL.md`. For common tasks:

- product launch → `references/tactics/launch.md`;
- outreach → `references/tactics/outreach.md`;
- competitor monitoring → `references/tactics/monitoring.md`;
- SEO/content → `references/ideas/content-seo.md`;
- pricing → `references/psychology/pricing.md`;
- persuasion/copy → `references/psychology/persuasion.md` and `references/hook-frameworks/SKILL.md`.

## Verification

Before final output, check:

- exactly one domain was selected;
- the relevant reference was actually read;
- the deliverable includes artifact, output location, and success criteria;
- no private/customer-specific assumptions were introduced.
