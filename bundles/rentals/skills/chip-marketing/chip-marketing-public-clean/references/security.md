# Security & Permissions

Agentic marketing workflows can read sites, draft copy, submit forms, send messages, and call APIs. Treat that as production power.

## Best practices

- Use least-privilege accounts and scoped API keys.
- Keep access material out of skills and archives.
- Start with read-only monitoring before enabling writes.
- Require approval for public posting, email sending, paid ads, pricing changes, or customer-facing messages.
- Log actions and verify external side effects.
- Review any third-party skill or script before installing it.
