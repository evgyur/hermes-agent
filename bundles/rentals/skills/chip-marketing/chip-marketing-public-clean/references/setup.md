# Setup Requirements

## Runtime

- Agent runtime with tool access appropriate to the task.
- Browser automation only when a workflow requires form submission, site checks, or visual QA.
- Messaging/email/API integrations only with explicit user approval and least-privilege access material.

## Launch assets

Create a local campaign folder when needed:

```text
./launch-assets/
├── logo.png
├── banner.png
├── screenshot-1.png
├── screenshot-2.png
└── positioning.md
```

## Safety defaults

Start read-only. Move to posting, emailing, or paid actions only after approval and a small test run.
