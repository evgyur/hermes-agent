# Workflows

## "Launch from zero"

1. `ideas/launches.md` → choose launch strategy
2. `tactics/launch.md` → execute 100-platform blitz
3. `psychology/persuasion.md` → apply urgency/scarcity
4. `playbooks/SKILL.md` → Product Hunt day-by-day

## "Scale existing channel"

1. `ideas/content-seo.md` → content strategies
2. `tactics/content.md` → content syndication
3. `psychology/growth-models.md` → feedback loops, compounding
4. `ideas/paid-ads.md` → paid amplification

## "Improve conversion"

1. `psychology/buyer-psychology.md` → understand barriers
2. `psychology/persuasion.md` → apply influence techniques
3. `psychology/pricing.md` → optimize pricing presentation
4. `hook-frameworks/SKILL.md` → rewrite hooks

## "Build marketing system"

1. `setup.md` → infrastructure requirements
2. `tactics/` → choose 2-3 tactics to start
3. `ideas/` → select strategies by stage/budget
4. `security.md` → permissions and safeguards
