# Cover QA

Check before handoff:

- file opens;
- dimensions/aspect match target;
- headline readable at phone preview size;
- exact text spelling and terminology are correct;
- logo/CTA present and not cropped;
- no generated fake text/logo/watermark;
- safe margins respected;
- no collisions between subject, cards, title, and logo;
- cover thesis matches the source/topic;
- brand family is recognizable;
- no stale placeholders, dates, filenames, or previous-task artifacts.

If any production-blocking issue exists, regenerate or repair before delivery.
