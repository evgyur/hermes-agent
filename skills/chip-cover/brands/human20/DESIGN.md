# Human20 cover design system

Human20 / Человек 2.0 covers are premium educational/product covers for AI implementation, agents, workflows, tools, and practical adoption. They should feel technical but human, premium but practical, and recognizably `Человек 2.0`.

## Approved names

Use `Человек 2.0`, `Среда внедрения ИИ`, and `human20.app`. Avoid “контур” and fake sub-brands.

## Assets

```text
runtime-supplied brand logo path
runtime-supplied brand mark path
runtime-supplied brand fonts directory
```

If missing, search Human20 app assets. Do not generate a fake logo.

## Families

- Dark GitHub/code-card: Hermes/OpenClaw/MCP/GitHub/tool/debug stories.
- Light Human20 product card: command cheat sheets, reminders, product UX, payment/Среда promos.
- Premium metaphor + overlay: broader public channel concepts.

## CTA

Public/channel: `Подписаться: @human20`.

Existing participant/payment promo: `Остаться в Среде` + visible URL such as `human20.app/payment`.

## Headline rules

Headline must be outcome/conflict/capability, not a process label.

Good: `Агентам дали\nтерминал\nдля рынка`, `Статья должна\nпопасть в ответы ИИ`.

## Renderer

Use `chip-cover/scripts/render_human20_cover.py` for the current dark GitHub/code-card family.

## QA

Official logo visible; CTA correct; footer correct where required; headline is a hook; Russian readable on phone; no cropped text; dynamic badge centering; no tofu glyphs; numeric claims checked; final PNG exact target size.
