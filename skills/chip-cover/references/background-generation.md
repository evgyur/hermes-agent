# Background generation

`chip-cover` may ask `img` to generate a background/key art. The background is not the final cover if exact text/logo/CTA is needed.

Prompt pattern:

```text
Create a premium editorial key art background for a square social cover.
Subject: <visual metaphor>.
Mood: <brand mood>.
Composition: reserve clean negative space at <zone> for headline and CTA overlays.
Palette: <brand palette>.
Style: <specific visual style>.
Important: NO readable text, NO letters, NO numbers, NO logos, NO watermark, NO UI labels.
```
